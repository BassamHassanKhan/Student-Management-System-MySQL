# Student-Management-System-MySQL


##  Overview
This project is a simple Student Management System built using MySQL. It manages students, courses, and their enrollments.

##  Database Structure
- students
- courses
- enrollments

##  Features
- Add and manage students
- Manage courses
- Track student enrollments
- Perform data analysis using SQL

## Technologies Used
- MySQL

##  SQL Concepts Used
- JOIN
- GROUP BY
- COUNT
- HAVING
- Foreign Keys

##  How to Run
1. Open MySQL Workbench
2. Run the SQL file: `student_management_system.sql`
3. Execute queries

##  Sample Queries
- Get students with courses
- Count courses per student
- Find popular courses
